SetupCore requirementRealtime chatReview / bonus

Project setup

Build: Create React + TypeScript app, Java Spring Boot app and PostgreSQL connection.

Test: Open frontend and backend. Check mobile and desktop layout.

Step 2Core requirement

Register / login / logout

Build: Build unique email registration, bcrypt password storage, JWT login and logout from every page.

Test: Register, login, refresh protected page and logout.

Step 3Core requirement

Profile + picture

Build: Build complete/edit profile and profile picture add/change/remove with 👤 fallback.

Test: User cannot see recommendations before completing profile.

Step 4Core requirement

Bio + preferences

Build: Add at least 5 bio points and target preferences: hobbies, location, availability, social style, activity preference, looking for.

Test: User can save and change bio and preferences.

Step 5Core requirement

Seed/reload users

Build: Create a separate seed/reload method with 200 fictitious users from Estonia localities.

Test: Drop DB, run empty app, reload users.

Step 6Core requirement

Recommendations

Build: Build scoring logic: good matches first, poor matches refused, same location, max 10 ids, dismissed users hidden.

Test: Test obvious good match, obvious poor match and dismissed recommendation.

Step 7Core requirement

Required endpoints + privacy

Build: Build required /users, /profile, /bio and /me endpoints. Keep email private. Return 404 when not allowed.

Test: Endpoints return correct data, ids, and 404 for blocked profiles.

Step 8Core requirement

Connection requests

Build: Build send request, incoming requests list, accept and reject.

Test: Request can be sent, accepted and rejected.

Step 9Core requirement

Connections + disconnect

Build: Build /connections id list, connected profile view, start/resume chat button and disconnect.

Test: Connected users can see each other. Disconnect removes access.

Step 10Realtime chat

Chat history

Build: Build chat list newest first, one chat history per pair, paginated messages and timestamps.

Test: Both users see same history. API data is paginated.

Step 11Realtime chat

Real-time chat + unread

Build: Use Spring WebSocket + STOMP. Message appears immediately, chat list reorders and unread icon appears.

Test: Works in real time without polling.

Step 12Review / bonus

README + final review

Build: Finish README, setup guide, usage guide, seed commands, review demo and optional bonuses.

Test: Run full mandatory test list before submit.
